# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please email the maintainers directly or use GitHub's private vulnerability reporting feature.

## Response

We will acknowledge receipt of your report within 48 hours and aim to provide a fix or mitigation within 90 days, depending on severity.

## Supported Versions

Only the latest release is actively maintained and receives security updates.
